GooeyGame

Make real 2D games with init(), update() and draw().

Every game is one class with three methods. GooeyGame runs the game loop, reads the keyboard and mouse, and plays your sounds.

Read the docs Get started

Download GooeyGame.jar and GooeyGame-sources.jar. Runs on Java 8 or newer.

What’s in the cup

  • A real game loop

    init() runs once, update(dt) about 60 times a second, and draw(d) paints each frame.

  • Keys, mouse, sprites and sound

    Ask Input.isKeyDown(Key.LEFT), animate with sprite sheets, and play sound effects and music from your assets folder.

  • Friendly when things break

    A missing image draws a pink box and warns once. A missing sound warns once and stays quiet. Your game keeps running.

Your first sip

The smallest possible game: a ball that glides to the right.

import gooeygame.*;

public class Hello implements GameListener {
    private double x = 0;

    public void init() { }

    public void update(double dt) {
        x += 200 * dt;    // 200 pixels per second
    }

    public void draw(Draw d) {
        d.clear("black");
        d.fillCircle(x, 300, 20, "yellow");
    }

    public static void main(String[] args) {
        GameRunner.start(new Hello(), "Hello", 800, 600);
    }
}

Get started in three sips

  1. Grab the jars

    Download GooeyGame.jar and GooeyGame-sources.jar.

  2. Drop them in lib

    Put both jars in your project’s lib folder. VS Code shows the docs when you hover over GooeyGame code.

  3. Import and run

    Add import gooeygame.*; at the top of your file, write your code and hit Run.
